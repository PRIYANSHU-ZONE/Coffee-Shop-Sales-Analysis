Coffee Shop Sales Analysis — SQL & Power BI

About the Project

I created this project to practice **SQL and Power BI** using coffee shop sales data. The main goal was to understand sales performance and create useful visualizations from the data.

What I Analyzed

* Total Sales, Orders and Quantity Sold
* Monthly Sales Growth
* Sales by Store Location
* Product Category and Top Products
* Weekday vs Weekend Sales
* Daily and Hourly Sales

Tools Used

* MySQL
* SQL
* Power BI
* GitHub

Project Files
`Coffee_Shop_Sales.sql` – SQL queries used for analysis
`coffee shop sales dashboard.pbit` – Power BI dashboard
`Power BI dashboard.png` – Dashboard preview

What I Learned

Through this project, I improved my understanding of **SQL queries, data analysis, KPI calculation, and Power BI dashboard creation.
